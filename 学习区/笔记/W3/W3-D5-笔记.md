## 速览：相机与 Tag（10 分钟，不计入验收）

> 每日 Unity 速览第 1 篇（计划「每日 Unity 速览」，F40）。只认识概念，打开看一眼就停，不出自测题。起因：W3-D4 第 1 节答疑时 Scene 视图相机、Tag、`cameraType` 混在一起。

**前提**：Unity 6000.3 编辑器，打开工程里任意一个有 Camera 的场景。

1. **相机类型（`CameraType`）**：Unity 给每台相机标一个用途。【原文】[Unity 6.3 · CameraType](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/CameraType.html)「The Unity Editor sets the type of a camera based on what it is used for」，共列出 5 种，常见的是两种：
   - `Game`：「a regular in-game camera」。同页写明「A camera in the Scene Hierarchy will have the type Game.」，也就是你放进场景、在 Hierarchy 里能选中的 Camera。【推断】Game 视图和打包后的游戏用的就是它。
   - `SceneView`：「rendering the Scene View in the Editor」，编辑器 Scene 视图自己用的相机。【推断】它不在 Hierarchy 里，你选不中它。
   - 另外三种是 `Preview`（编辑器里的预览）、`VR`（编辑模式下的 VR）、`Reflection`（反射探针）。
2. **标签（Tag）**：【原文】[Unity 6.3 · Assign tags to GameObjects](https://docs.unity3d.com/6000.3/Documentation/Manual/Tags.html)「A tag is a reference word which you can assign to one or more GameObjects.」Tag 是挂在 GameObject 上的一个名字，用来在脚本里找物体。内置的 `MainCamera` 有专门用途：【原文】[Camera.main](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Camera-main.html)「The first enabled Camera component that is tagged "MainCamera"」。
3. **两者不是一回事**【原文+推断】：`CameraType` 由编辑器按用途设置（见第 1 点原文），Tag 由你自己指定（见第 2 点原文）。把 Scene 视图相机和 Game 相机分开的是 `CameraType`，不是 Tag。
4. **和本工程的关系**：【原文·代码】`GaussianBlur_RendererFeature.cs:50-52` 判断的是 `cameraType == CameraType.Game`，所以只有 Game 相机才加入模糊通道；它不看 Tag。

**看一眼（2 分钟）**：选中 Hierarchy 里的 Camera，在 Inspector 最上方看它的 Tag 是什么。
