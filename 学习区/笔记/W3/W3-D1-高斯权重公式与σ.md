# W3-D1 专题：高斯权重公式与 σ 到底是什么

> 日期：2026-10-07 ｜ 对应：W3-D1 第 0 节 · 0a「σ 与标准差」（W2 债务）
> 状态：✅ 已弄懂 ｜ 顺带引出 0b「为什么要预留固定的最大采样数」

---

## 1. 公式

$$
w(i) = e^{-\frac{i^2}{2\sigma^2}}, \qquad \text{最终权重} = \frac{w(i)}{S}, \quad S = \sum w(i)
$$

一句话读法：**这个点离中心几个 σ → 平方 → 取负 → 用 e 变成 0~1 的权重 → 大家一起除以总和。**

---

## 2. 逐项拆解

| 部分 | 含义 | 为什么这样写 |
|---|---|---|
| `i` | 采样点**离中心像素几格**（中心 0，邻居 ±1、±2…），单位是像素 | 不是像素的绝对位置，是相对中心的距离 |
| `σ` | 这座「山」的**半宽**：从中心走到权重降到 0.61 的横向距离，单位也是像素 | 你自己设定的数字，规定模糊有多宽 |
| `i / σ` | **相对距离**：这个距离对于这次的模糊范围来说算远还是算近 | 同样 2 格，σ=1 时算远（=2），σ=4 时算近（=0.5）。后面几步只认这个比值 |
| 平方 `(i/σ)²` | ① 去掉正负号 → **左右对称**；② **近处掉得慢、远处掉得快**（0.5²=0.25 几乎不掉，2²=4 猛掉） | 让曲线中心是**圆顶**而不是尖角，两边平滑陡降 → 钟形。不平方用 `|i|` 会在中心出尖角 |
| 分母里的 `2` | 约定：加上它，σ 正好等于统计学里的**标准差** | 不改变曲线形状，只是换个单位。好处是能直接用 68% / 95% / 99.7% 规律，知道采到 3σ 就够 |
| 负号 | 距离越大，指数越负 | 配合 e 使用，保证越远权重越小 |
| `e^(...)` | 把「多远」换成「多重」 | 指数 0（正中心）→ 1，指数越负 → 越平滑地趋近 0，永远不为负 |
| 除以 `S` | **归一化**：所有权重加起来正好 = 1 | 保证画面亮度不变（总和 > 1 变亮，< 1 变暗） |

### 为什么不用完整公式前面的系数 \( \frac{1}{\sigma\sqrt{2\pi}} \)？
- 那个系数是让**连续**曲线下面积 = 1。
- shader 里只取有限的整数点，还在 3σ 处截断了，乘上它离散和也不会正好是 1。
- 它对每个点都一样，不影响各点之间的比例。
- 所以先用 `exp(...)` 算相对大小，最后统一除以 S 一步到位。

## 3. σ 到底是什么（看图）

（示意图：σ=1 与 σ=2 两条曲线对比，克瑞已自行放入笔记）

- **横坐标** = `i`：离中心几格；**纵坐标** = 权重（未归一化）。
- 两座山**一样高（都是 1）**，σ **只改变横向宽度**。
- 1σ 处权重都降到 **0.61**；3σ 处**几乎为 0**（σ=1 在 3 格，σ=2 在 6 格）。
- **σ 翻倍 → 整座山横向拉宽一倍 → 要采样的格子也多一倍。**

> **一句话记住：σ = 你想让模糊有多宽，用像素量。**
> 实际被拉进来的范围 ≈ 中心左右各 3σ 格。

### 注意：「像素」指的是哪张图上的像素
- 开了 `downSample`：一格 = 降采样后那张 RT 上的一个像素，不是屏幕像素。
- `_BlurSpread` 拉大采样间距：一格也不再等于一个像素。

---

## 4. σ 越大为什么越糊

采样点固定时：σ 越大 → 外圈格子分到的权重越大 → 混进来的邻居颜色越多 → 越糊。

### ⚠️ 坑：采样点不够时（引出 0b）
- 若 `i` 最多只到 ±3（7 个点），按 3σ 规则只够 **σ = 1**。
- σ 设到 2，山本应延伸到 6 格，却在 3 格处被**截断** → 外面本该有权重的邻居被丢掉。
- 继续调大 σ，结果越来越**不像高斯**，越来越接近 7 格的**平均模糊**，糊不到想要的程度。
- 所以：想支持的最大 σ 决定了采样数组至少要留约 `6σ + 1` 格；而 shader 数组长度要**编译时定死**。
