## 今天学到了什么（收口）

1. **小改动看不出整帧变化**：拷贝省下 0.049 ms，比整帧起伏（前 1.51 ms、后 0.73 ms）小得多，所以「后 3.11 > 前 2.745」只是晃动，不是变慢（第 6 节、题 2）。这条是你自己从「后比前大」推出来的。
2. **关掉两张 RT，省的东西都对得上**：RT 少 10.368 MB，正好是两张之和；Draw Calls、SetPass 各少 2【观察】，每步拷贝在 Frame Debugger 里各是一次 Draw Procedural（第 6 节、题 1、预测题 2）。
3. **改相机，不改管线资产**：管线资产整个工程共用，关掉会弄坏另一个场景 `Scene-10-Glass+Chapter11.unity` 里的玻璃，因为 `GlassRefraction.shader:97` 读 `_CameraOpaqueTexture`（第 1 节第 4 条、题 3）。读图的是 shader，`.mat` 只存参数。
4. **设置是一层层往下找的**：Graphics / Quality 设置指向 `PC_RPAsset`，它带着 `PC_Renderer`；相机上的选项选 Use Pipeline Settings 就跟管线资产走，选 Off / On 就自己覆盖（第 1 节第 3 条；图 [01-管线设置分层](../../图片/W5/D2/01-管线设置分层.png)）。
5. **Profiler 里同名两条是一外一里**：外层是 Render Graph 执行 pass 的计时，里层是拷贝函数自己的计时，外层的 GPU ms 已含里层，只抄外层；`Inl_` 开头的是 CPU 即时计时，不记 GPU（第 3 节，V71）。GPU 时间要在 GPU Usage 模块里看 GPU ms 列。
