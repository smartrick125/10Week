## 2. 手推 5 点一维高斯核（90 分钟）

取 `σ = 1`。先算未归一化值 `a(i) = exp(-i² / (2σ²))`，再算 `S = a(0) + 2a(1) + 2a(2)`，最后得到 `w(i) = a(i) / S`。保留至少 4 位小数，记录计算过程，不只填答案。

| 偏移 i | -2 | -1 | 0 | +1 | +2 |
|---|---:|---:|---:|---:|---:|
| 未归一化 a(i) | 0.1353 | 0.6065 | 1 | 0.6065 | 0.1353 |
| 归一化 w(i) | 0.0545 | 0.2442 | 0.4026 | 0.2442 | 0.0545 |
| shader 中的权重 | 0.0545 | 0.2442 | 0.4026 | 0.2442 | 0.0545 |

**归一化分母 S 的计算**：2.4836

**五个 w(i) 的和**：1.0000

**为什么左右权重对称、中心最大？** 对称为了保持不偏向左边颜色或者右边颜色 中间最大时高斯模糊方程的核心要点距离中心越远 颜色的权重越小

**与 shader 数字是否一致？若有尾数差，原因是什么？** 一致

### 概念扫盲
> 01. exp(x) 就是 (e^x)，其中 (e≈2.71828)  
> 02. i代表自己选择的采样的位置 相对中心的采样偏移编号  
> 03. σ 读作 sigma，是高斯函数的宽度参数，也叫标准差  
> · σ小 离开中心后权重下降的快  
> · σ大 去找你红下降的慢 较远的位置影响也大  
> · 因为 σ² 在分母所以越大越这个数字整体越接近于0，远处的权重也就越大
> 04. 为什么使用 exp(x)?  
> · 因为选择的是高斯形状的权重分布：离中心远 -> i^2越大 -> 指数负数越大 -> 离中心远权重小  
> 05. _BlitTexture_TexelSize.xy：(1/纹理宽度, 1/纹理高度)，即一个纹素对应的 UV 距离  
> 06. 采样函数展开：
> ```hlsl
> SAMPLE_TEXTURE2D_X_LOD(
>     _BlitTexture,        // 从哪张纹理取颜色
>     sampler_LinearClamp, // 怎样过滤、怎样处理越界
>     uv + offset,         // 取颜色的位置
>     _BlitMipLevel        // 从哪一级 mip 取
> )
> ```

## 3. 为什么分纵向、横向两次做（60 分钟）

**文字作答，不必画图**：假设采样间距为 1 个纹素，以一个输出像素为例，直接二维采样会读取原图中的 5×5 区域。改成先纵向、再横向后，横向采到的每个中间颜色已经包含了原图哪些位置的信息？为什么两遍合起来仍能包含这个 5×5 区域？

**我的解释**：因为shader0已经进行了纵向模糊了包含了纵向模糊的信息然后横向模糊计算的时候就已经包含了纵向牧户的信息所以两遍合起来仍能包含这个 5×5 区域

- `G(x, y) = g(x) · g(y)` 在这里意味着什么？相当于对于中心横轴纵轴的偏移 指数运算法则天生可拆所以就可以拆为横向模糊*纵向模糊 而内部的x，y代表各自方向的偏移 综上所述就可以合并为一个二维权重结果
- 直接 5×5 需要多少次纹理采样？每像素 直接二维25 总:N x N x H x L
- 分成一次纵向和一次横向，各采多少次，合计多少次？两遍一维各5次合计10次，总: 2 x N x H x L
- 为什么纵向结果不能直接写回正在读取的同一张纹理？因为普通的blit不能同一张纹理既写入又读取

**检查点**：不看代码，讲出「先纵后横」如何得到二维模糊效果。自评：通过 / 待补。
- 就是需要三张纹理配置tempA tempB 一张当前摄像机视图 然后tempA到tempB做纵向模糊 tempB到tempA做横向 然后tempA写回摄像机
